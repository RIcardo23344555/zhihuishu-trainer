# 智慧树加速器 · 修改器版

Windows 上给智慧树（zhihuishu.com）网页版用的**挂机刷课 + AI 做章测**小工具。
一个 Tkinter 面板当「修改器」，通过 Chrome DevTools 协议把脚本注入到播放页，再用**真实鼠标点击**
（Windows 输入队列，不是合成事件）去操作播放器和试卷。

> 只在自己的账号上、自己承担后果地使用。它不破解任何加密，也不改服务端数据：
> 刷课走的是**平台自带的 1.5 倍速**，进度按真实观看时长记账。

---

## 它解决什么问题

| 平台给的 | 这个工具加的 |
|---|---|
| 手动点下一节 | 一节刷到 **100%** 自动切下一节；没满就从头重播直到满 |
| 手动关弹题（不关会暂停） | 自动选中 + 关闭弹题，关完自动续播 |
| 手动调 1.5 倍速 | 页面刷新后倍速掉了会自动补回 1.5× |
| 章测一题题手查 | AI 读题作答、真实鼠标点选、可一键提交 |

**做不到**：让进度按 8 倍速涨。心跳请求体是 AES 加密的，进度只认真实观看时长，
所以本工具只做「1.5× 老实挂机」，不做跳格刷进度。

---

## 环境要求

- Windows 10 / 11
- Microsoft Edge（Chrome 也可以，改一行路径即可）
- Python 3.8+（安装时勾选 `Add Python to PATH`）

---

## 安装

1. 下载本仓库，解压到任意目录（路径别带空格更稳）。
2. 双击 `启动.bat`。
   - 它会用**独立的浏览器配置目录**（`%LOCALAPPDATA%\zs-trainer\profile`）启动 Edge，
     并打开 `--remote-debugging-port`，所以**不会动你日常用的浏览器**。
3. 第一次用：在弹出的浏览器里登录一次智慧树（知到 APP 扫码 / 学号密码都行）。
   登录状态会记住，以后不用再登。
4. 进入课程、点开任意一节开始播放 → 面板状态行出现 `播放中 xx%` 就接上了。

> 为什么不用你自己的浏览器配置？Chrome/Edge 136+ 拒绝在默认用户目录上开调试端口，
> 而且 cookies 是 App-Bound 加密的，复制配置也搬不过去。所以是「独立配置 + 登录一次」。

## 用法一：挂机刷课（不需要任何 API key）

面板点 **「挂机刷课（1.5× · 满 100% 自动下一节）」**，然后放着别管。

- 用平台自带的 1.5 倍速播放，进度按真实时长涨；
- 每节目录显示 100% 才切下一节，没满就重播；
- 自动静音、自动关弹题；
- 一门 44 节的课，1.5 倍速大约 5~6 小时。

---

## 用法二：AI 做章测（需要一个 DeepSeek API key）

1. 去 <https://platform.deepseek.com> → API keys → 创建一个，充 10 元够跑几十次章测。
2. 面板「AI 章测用的 DeepSeek Key」里粘贴 → 点 **保存**（存在本地 `api_key.txt`）。
3. 在浏览器里点开某一章的「平时测试」（会新开标签页到答题界面）。
4. 回到面板点 **「AI 做章测并提交」**；想先看一眼就点 **「AI 做章测（不提交）」**。

原理：题干在页面上是被字体混淆抹掉的（DOM 里搜不到），所以程序拦 `doHomework` 接口的
响应拿明文题库 → 丢给 DeepSeek 选答案 → 按选项 `id` 匹配（页面选项顺序每次随机）
→ 真实鼠标点选 → 提交。

一次 3 题的小测约 20 秒、1~2 分钱。

## 注意事项（重要）

- **会占用鼠标**：切下一节、补倍速、点弹题、重播时会抢一下前台，每次约 1~2 秒。
  能上网/看视频/聊天，但**别在打游戏或专注打字时挂**。
- **浏览器窗口别最小化**：最小化后读不到元素坐标，点不动。可以放到后台或另一个桌面。
- **面板别关**，它是遥控器。
- **电脑别睡眠**：设置 → 系统 → 电源 → 接电源时「从不」。
- 课程页偶尔会被平台踢回首页，程序会自动拉回，不用管。
- **不要同时开两个播放页**刷同一门课。
- `api_key.txt` 是你的私钥，**分享给别人前请清空或删掉**。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 「页面里没有找到视频」 | 还没点开某一节课 |
| 一直「正在启动…」 | 关掉面板和所有相关浏览器，重新双击 `启动.bat` |
| 章测报「没有打开作业考试页面」 | 先在浏览器里点开那一章的「平时测试」 |
| 提示「还没填 DeepSeek Key」 | 面板上方那一栏粘贴 key → 保存 |
| 弹题卡住不动 | 日志会写「弹题卡住了」；把面板日志最后几行发出来 |
| 想看它干了什么 | 同目录 `log.txt` |

## 技术要点（给想看代码的人）

- **注入**：CDP `Page.addScriptToEvaluateOnNewDocument`，页面刷新/换节后自动重新注入，
  这是「自动连播」能跨页面生效的基础。
- **为什么必须用真实鼠标**：站点会检查 `event.isTrusted`，合成 `element.click()` 和
  CDP `Input.dispatchMouseEvent` 都会被判定异常并把你踢回首页；只有 Windows 输入队列
  （`SetCursorPos` + `mouse_event`）不被判。
- **为什么不用 `video.playbackRate`**：播放器自己包了一层 setter，且服务端不认；
  平台原生 1.5× 才是服务端认可的真实倍速。
- **反爬**：题干用自定义字体 + 空 div 抹掉，DOM 里搜不到；解法是拦 `doHomework` 响应。
  选项顺序每次随机，必须按 `input.value`（选项 id）匹配，不能按 A/B/C/D。
