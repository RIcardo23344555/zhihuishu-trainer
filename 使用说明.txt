========================================
 智慧树加速器 · 修改器版  使用说明
========================================

【怎么用，就三步】
1. 双击「启动.bat」
   → 弹出小面板（修改器），并自动打开一个浏览器窗口。
2. 第一次用：在打开的浏览器里登录一次智慧树
   - 手机「知到 APP」→ 扫一扫 → 扫浏览器上的二维码
     或者用「账号登录 / 学号登录」直接输账号密码
   登录状态会记住，以后不用再登。
3. 进入你的课程，点开任意一节开始播放
   → 面板「状态：播放中 xx%」开始跳，就说明接上了。

【一、刷课：点「挂机刷课（1.5× · 满 100% 自动下一节）」】
· 用平台自带的 1.5 倍速播放（不是脚本改的，服务端按真实时长记账，进度真涨）
· 每一节目录显示 100% 才自动切下一节；没满就从头重播，直到满
· 自动静音、自动关弹题（弹题不计分，只是挡住了播放，所以必须点掉）
· 点一下按钮，然后放着别管（可以睡觉）
· 一门 44 节的课，1.5 倍速大概 5~6 小时

【二、章测：点「AI 做章测并提交」】
· 第一次用：在面板「AI 章测用的 DeepSeek Key」里粘贴你的 key → 点「保存」
   （key 在 platform.deepseek.com → API keys 创建，充 10 元能跑几十次章测）
   没填 key 时点章测按钮会提示你先填，挂机刷课不受影响。
· 先在浏览器里点开某一章的「平时测试」（会在新标签页打开试卷）
· 回到面板点「AI 做章测并提交」
· 程序会：抓题（走接口拿明文）→ 问 DeepSeek → 用真实鼠标逐题点选 → 提交
· 三题的绪论测试约 20 秒，一次花费 1~2 分钱
· 想先看一眼再交：点「AI 做章测（不提交）」，它会填好停下，你自己按「提交作业」
· 注意：它会临时暂停挂机点击，跑完自动恢复

【面板上还有什么】
· 加速倍率：1~16 倍。>1.5 走「跳格」，只快画面、不涨进度，一般用不上
· 暂停加速 / 继续加速：临时停一下
· 下一节：手动跳下一节
· 三个开关：自动静音 / 看完自动下一节 / 自动处理弹题
· 状态行：「进度 xx%」= 平台记的真实百分比，括号里是当前模式

【会占用鼠标吗】
· 会，但很少：切下一节（1.5 倍下约 7~10 分钟一次）、倍速被重置时补点、弹题 2 下
· 每次约 1~2 秒，鼠标会跳到浏览器上点一下，浏览器会闪到前台
· 所以：能上网、看视频、聊微信；别在打游戏或专注打字时挂着

【必须注意】
· 浏览器窗口别最小化（最小化后取不到坐标，点不动）
· 面板别关（它是遥控器）
· 电脑别睡眠：设置 → 系统 → 电源 → 屏幕和睡眠 → 接电源时「从不」
· 课程页偶尔被平台踢回首页，程序会自动拉回，不用管
· 不要同时开两个播放页刷同一门课

【出问题了怎么办】
· 「页面里没有找到视频」→ 还没点开某一节课
· 一直「正在启动…」→ 关掉面板和所有浏览器，重新双击「启动.bat」
· 章测报「没有打开作业考试页面」→ 先在浏览器里点开那一章的平时测试
· 想看重启前干了什么 → 同目录 log.txt

【别人也想用 / 换一台电脑】
· 把整个 zs-trainer 文件夹拷过去（api_key.txt 别一起拷，里面是你的 key）
· 那台电脑要装 Python 3（python.org 下载，安装时勾选 Add Python to PATH）
· 双击「启动.bat」；第一次用照上面第 2 步扫码登录一次
· 想用 AI 章测的话，在面板的 Key 那一栏填他自己申请的 key，点保存
· 不想用 AI、只刷课：不填 key 也能用，章测那三个按钮会提示先填 key

【文件说明】
启动.bat        双击这个
trainer.py      主程序（面板 + 注入 + 连点器 + AI 章测入口）
inject.js       注入网页的逻辑（倍速 / 连播 / 弹题 / 满 100% 才走）
exam.py         章测作答器（抓题 + DeepSeek + 真实鼠标点选）
api_key.txt     DeepSeek 的 key（别发给别人）
log.txt         运行日志
